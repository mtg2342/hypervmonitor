    Backup Monitoring
    Veeam Backups
    Scan Veeam B&R cmdlets and the Windows Event Log for backup job status. Works for both Veeam Backup & Replication and the free Veeam Agent.
    Windows Backup
    Read Windows Server Backup status via Get-WBSummary, with fallback to the Microsoft-Windows-Backup event log. Shows last backup time, result, target, and version count.
    Sensor Sources
    Temperature monitoring uses multiple data sources. Below shows which categories are currently producing readings. SMART (storage) and ACPI (CPU thermal zones) are built into Windows.     Install LibreHardwareMonitor
    Downloads the latest release from GitHub, extracts it to C:\Program Files\LibreHardwareMonitor, registers a logon scheduled task, and starts it now so the WMI namespace becomes available immediately.
    Diagnose temperature sources
    Runs the temperature scan right now and shows exactly what each provider (ACPI, SMART, LHM, OHM) returned or why it failed. Useful when temperatures aren't appearing on the dashboard.
